# Accessibility in SPV

Read [the checklist](references/checklist.md) and select the entries that apply to the requested features and states. For each required outcome, name the user action, expected observation, and verification method. Record the reason for exclusions that affect the task.

Ask about a consequential edge case the developer can reason through. Incorporate the developer's actual answer into the plan. Proceed with implementation after the developer approves that exact revision. When called for a single role, follow that role's handoff and return the required evidence.

Exercise the approved interactions on the exact candidate. Record evidence per state. Automated scans complement keyboard, zoom, screen reader, and other manual checks where applicable. Keep required checks unassessed when the necessary tool or observation is unavailable. Scope the verdict to the current candidate and the listed checks.
